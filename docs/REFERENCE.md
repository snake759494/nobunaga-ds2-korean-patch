# 참고 자료 (네이버 카페 문서)

**우주산너구리** 님의 정리글을 근거로 삼았습니다. GitHub 이슈
[#2](https://github.com/snake7594/nobunaga-ds2-kr/issues/2) 로 제보해 주신 자료입니다.

|---|---|
| 화면설명편 (2026-08-11) | 스타트 메뉴 · 시나리오 · 환경설정 · 평정 · 내정/군사/인사/대외/정보 · START 기능의 전체 항목 표기 |

| 이미지 교체 문의 (2026-07-29) | 영지명 2글자 제한으로 서로 다른 국이 같은 이름이 되는 문제 제보 |

## 반영 원칙

- **고정폭 이름 필드는 음독으로.** 영지명 필드는 4바이트(한글 2자)뿐입니다.
  일본어 읽기를 넣으면 잘려서 `山城`·`大和`가 둘 다 `야마`가 됩니다.
  한자 2자를 음독 2자로 옮기면 폭이 정확히 맞고 서로 구분됩니다.
- **본문 산문은 손대지 않습니다.** `가이호 유쇼`는 사람 이름(海北友松),
  `미미카와`는 강 이름(耳川)입니다. 문자열 일괄 치환은 이런 것을 깨뜨립니다.
- **명령어와 전술이 같은 한자를 쓰면 구분합니다.** `流言`은 대외 명령일 때
  `풍문`, 전술 이름일 때 `유언`입니다. 문서의 구분을 그대로 따랐습니다.
- 문서의 표기를 따르지 않은 항목은 `data/reference/glossary_fix.json` 의
  `keep` 절에 이유와 함께 남겼습니다.

## 기계가 읽는 형태

- `data/reference/ryoseikoku.json` — 52개 율령국: 한자 → [음독, 일본어 읽기]
- `data/reference/glossary_fix.json` — 용어·전술 교정표와 유지 항목
- `tools/apply_reference.py` — 위 표를 번역 데이터와 그래픽 라벨에 적용

```bash
python tools/apply_reference.py --dry-run   # 무엇이 바뀌는지만 출력
python tools/apply_reference.py             # 실제 적용
```
